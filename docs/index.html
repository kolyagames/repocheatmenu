Призрак, которого слышат

Ваш аватар не создаётся у других игроков — фильтр режет исходящие события Instantiate / Destroy / сериализации для видов, созданных вами. Но вы по-прежнему в комнате: видите игру, слышите чат, можете хватать предметы.

С версии 1.0.112 фильтр пропускает ровно один prefab — Voice, это игровой голосовой PhotonView. Остальным игрокам достаётся «кукла с микрофоном» без модели, звук приходит 2D (нет 3D-позиции, т.к. аватара рядом нет). Мод у них ставить не нужно.

  • Телекинез: луч к предмету на прицеле, Shift — пнуть
  • Прыжки к ценностям, грузовику, точке выхода, выбранному игроку
  • Слежка глазами за игроком
  • Пауза в комнате: хост не видит вас в игре, но видит в Steam-лобби
v1.0.112

Как слышат голос

  1. Фильтр пропускает один prefab — Voice.
  2. У всех игроков появляется PhotonView в сцене на (1000,1000,1000).
  3. Recorder.UserData = ViewID.
  4. Их PhotonVoiceView.SpeakerInUse играет 2D-звук.

Поведение из блоков

Вкладка «Блоки» в меню F6. Собираете цепочку и запускаете. Автозапуск, повтор, условия, иначе, переменные, вызов других скриптов, прервать цикл. Скрипт сохраняется в BepInEx\config\RepoCheatMenu_Blocks\*.blk, экспортируется в буфер обмена для друзей.

Переменная заходов = 0
Повторить 3 раз
Зайти на случайный новый сервер
Если прошлый блок удался
Переменная заходов + 1
Ждать 60 с
Выйти в главное меню
Иначе
Прервать цикл

Конец «Повторить»
Уведомление «Обход закончен»

Установка в один клик

Через консольный лаунчер модпаков. Выбираете пак — DEFAULT / OPTIMIZATION / HD — и запускаете игру.

  1. Скачать

    Собрать локально через Собрать и обновить.bat в корне репо. Готовая папка попадает на рабочий стол в %USERPROFILE%\Desktop\RepoLauncher\.

  2. Запустить

    Открыть RepoLauncher.exe. Выбрать модпак и нажать «Играть» — лаунчер сам поставит мод в %LOCALAPPDATA%\RepoLauncher\profiles\<pack>\, запустит Steam с --doorstop-target-assembly.

  3. Играть

    В игре F6 — меню, G — телекинез (на предмете), ] — паник (скрыть всё, что рисует мод).

Сборка из исходников

Нужен .NET 8 SDK и PowerShell 5.1+.

# Полная сборка одной кнопкой (бамп версии, обфускация, лаунчер, рабочий стол)
powershell -File tools\build-all.ps1

# Только ядро мода, без лаунчера
cd RepoCheatMenu
dotnet build -c Release

# Горячая перезагрузка в живой игре
powershell -File tools\deploy.ps1

Два файла локально не распространяются (чужой копирайт): шрифты Apple SF Pro Display и иконки Rockstar RockIconData.cs. Как положить их обратно — рядом с README-файлами в репо.

Как это работает

Клиентский BepInEx + Harmony мод для R.E.P.O. (Unity + Mono + Photon PUN2). Не ломает сетевой код игры снаружи, работает с теми же API, что обычный игрок.
