# RockIconData.cs

Файл `RockIconData.cs` сгенерирован `tools/make-icons.py` из SVG-иконок
клиента Rockstar и в git НЕ коммитится — чужой защищённый контент.

**Как получить его локально:**

1. Положи SVG-иконки Rockstar в папку, которую знает `make-icons.py`
   (путь прописан в начале скрипта).
2. `python tools/make-icons.py` — скрипт запишет `RockIconData.cs`
   рядом с остальными `.cs`.
3. Сборка проекта (`dotnet build` или `Собрать и обновить.bat`)
   подхватит его автоматически.

Без этого файла проект НЕ соберётся — на него ссылается `MenuIcons.cs`.
Если нужны альтернативные иконки, замени словарь `RockIconData.Alpha`
на свои base64-битмапы 64x64 Alpha8 того же формата.
